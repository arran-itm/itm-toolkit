## Collaboration Notes
Please follow these strict rules if collaborating to this repository:

- Always work and test scripts from the dev branch.
- Store scripts in the appropriate folder with appropriate naming conventioins:
    - No Spaces
    - Commands should be documented in .md files inside code blocks and with documented parameters and explainations where applicable
    - Scripts should be saved in .ps1 or .sh files in the appropriate folder. scripts/(shellscript for.sh) or (powershell for .ps1)
- Once scripts/command documentation is fully reliable you can merge JUST that working file to the main branch. 
- Make sure to use comments in your scripts and provide info on running e.g. if you have parameters in the script declare them in comments at the top of the script file, alongside the usecase of teh script.
